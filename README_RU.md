## 👋 Привет!

Я — **Виктор Кузинов**, Python-разработчик.  
Этот проект — умный туристический агент, который:

- подбирает туры, отели и маршруты во Вьетнам  
- использует **Retrieval (RAG)** для встроенной базы знаний  
- подключает **Yandex WebSearch**, если данных не хватает  
- работает через Telegram-бота  

---

## 🚀 Технологии

- Python 3.10+  
- YandexGPT / Assistant API  
- Telegram Bot API  
- RAG (Retrieval Index + vector store)  
- WebSearch  
- Docker (опционально)  
- dotenv, requests, openai-python
